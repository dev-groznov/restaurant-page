# 🌆 Glitch & Grill — Cyberpunk Restaurant Page

A dynamic cyberpunk-themed restaurant website built entirely with vanilla JavaScript using DOM manipulation and Webpack.

## 🚀 Overview

Glitch & Grill is a high-tech gastronomy web application set in a dystopian 2088. The main goal of this project was to practice dynamic rendering without relying on static HTML content. Entire page layouts (Home, Menu, About) are created programmatically using JavaScript DOM methods.

## ✨ Features

- **Single Page Application (SPA) architecture:** Smooth content switching without full page reloads.
- **Dynamic DOM Rendering:** HTML elements generated purely via JavaScript.
- **Cyberpunk UI Theme:** Custom dark-mode styling with glowing neon accents, custom typography, and responsive cards.
- **Modular Codebase:** Clean ES6 module separation (`home.js`, `menu.js`, `about.js`, `index.js`).
- **Asset Bundling:** Managed with Webpack for seamless JS module exports and image loading.

## 🛠️ Built With

- **JavaScript (ES6+)** — DOM manipulation, ES Modules
- **CSS3** — Custom properties, Flexbox, CSS Grid, animations
- **HTML5** — Base template container
- **Webpack** — Asset bundling and dev server setup
